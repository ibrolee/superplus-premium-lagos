# Super Plus Refresh

Build a complete production-quality website for Super Plus Fitness & Spa, a modern fitness, spa and recovery center in Shomolu, Lagos, Nigeria.

This is a redesign/rebuild of an existing live business website. The goal is to create a substantially more premium, modern, cohesive and conversion-focused website while preserving the business information and functionality described below.

Do NOT create a generic gym template.

- High-quality photography

- Consistent spacing scale

MEMBER FUNCTIONALITY

IMPORTANT:

The current Super Plus website contains member-related functionality including:

- Member login/account
- Membership QR code
- Reception check-in
- Membership purchase
- Online registration

DO NOT remove these concepts.

Build the new public-facing design so these functions can be connected later.

Create clearly separated routes/components for:

/login
/member
/my-qr
/reception-checkin

Do not invent backend functionality.

If backend credentials/API endpoints are unavailable, use clearly marked integration placeholders.

The visual design of these pages should still match the main website.

==================================================
QR CHECK-IN UX

The QR system should NOT require members to repeatedly navigate through the website just to find their QR code.

Design the member dashboard so that after login:

- QR code is immediately visible
- Member name is visible
- Membership status is visible
- Expiry date is visible
- A large “SHOW QR CODE” button is available
- QR can be displayed full-screen on mobile

Also provide a persistent shortcut:

MY QR CODE

in the member navigation.

==================================================
RECEPTION CHECK-IN

Create a clean reception interface.

Large scanner area.

Show:

SCAN MEMBER QR CODE

Member name
Membership type

Expiry date
Check-in status

Use obvious states:

ACTIVE
EXPIRED
INVALID

Do not implement fake scanning logic. Build the interface so the actual QR/check-in backend can be connected.

IMPORTANT IMPLEMENTATION RULE

Do NOT sacrifice functionality for appearance.

The existing Wix website is already operational.

This project is primarily a visual and UX redesign.

Do not claim that payment, authentication, QR scanning, membership databases or backend integrations work unless they are actually connected.

Create clean integration points for those systems.

The final result should feel like a completely new Super Plus Fitness website while retaining the same business identity and functionality.

Before finishing, test every route at desktop and mobile widths and make sure there are no broken links, overflowing elements or inconsistent components.
